# MQTT-клиент (служба `mqtt`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** служба `mqtt` в `net_services`: узел `domain::mqtt` на `minimq` публикует статус, сведения и телеметрию платы брокеру, вшитому из `mqtt.toml`, и принимает `cmd/reboot`.

**Architecture:** узел — автомат `#[fsm::typestate]` над портом `ports::dial::Dial` (TCP-клиент `adapters::net::tcp::TcpClient` сам пережидает отказы — паузы в `domain` запрещены правилами проекта, `.claude/rules/domain.md`) и ядром сессии над любым `minimq::Io`; весь узел тестируется на host против поддельного брокера. Адрес — через шов `Broker` (`Fixed` сейчас). Генерация (хук), сборка (`build.rs` разбирает `mqtt.toml`), `xtask` (заготовка файла) и граф — по образцу служб `rest`/`ssh`.

**Tech Stack:** Rust `no_std`, Embassy (`embassy-net` 0.9, `embassy-time` 0.5), `minimq` 0.13.5, `heapless` 0.9, rhai-хук cargo-generate, Liquid.

**Spec:** `docs/superpowers/specs/2026-10-22-mqtt-design.md`

## Global Constraints

- Репозиторий — **шаблон**: в `crates-cross/**` живёт Liquid, `cross` в репозитории не собирается — проверяется `template-check` (MAINTAINING.md; изоляция — память «template-check isolation»: занят каталог → `TEMPLATE_CHECK_DIR=C:\tc-<имя>`).
- Liquid в корневом workspace (`domain`, корневой `Cargo.toml`) — только в комментариях `// {%- if net_services contains "mqtt" %}` / `# {%- … %}`.
- `minimq = { version = "0.13.5", default-features = false }`; фича `defmt` — через фичу `defmt` крейта `domain`, как у соседних зависимостей. Других новых зависимостей нет (в т. ч. build-зависимостей для разбора TOML).
- Узел: `restart: Never`, `TaskExit::Failed` не возвращает; отказ связи — лог и сразу снова `dial`; пауз в `domain` нет (`.claude/rules/domain.md`). Без голого `loop` в задаче узла.
- Буферы `minimq` — слоты фрагмента `= static`; буферы TCP — у `TcpClient`, их заводит `app` (`graph.rs`/`tasks/mqtt.rs`); без графа — `ConstStaticCell` в `tasks/mqtt.rs`.
- Темы: `<prefix>/<uid>/status` (QoS 1, retain, `online`; Will `offline`), `/info` (QoS 1, retain, JSON `DeviceInfo`), `/telemetry` (QoS 0, `{"uptime_s":N}`, раз в 10 с), `/cmd/reboot` → результат в `/cmd/reboot/result`. `uid` — 24 строчных hex; `client_id` — `<prefix>-<uid>`.
- Подписка `<prefix>/<uid>/cmd/#` с `RetainHandling::DoNotSend`; входящая команда с retain — игнор + лог.
- Сессия на брокере не сохраняется (`session_expiry_interval` не задавать); `Session` — новая на каждой попытке.
- `publish` QoS 0 не под `with_timeout` (не cancel-safe); под таймаутом — только `recv()`.
- Паузы `TcpClient`: 0 перед первой попыткой, затем 1, 2, 4, 8, 16, 30, 30 … с; сброс, если прошлое соединение прожило ≥ 30 с.
- `prefix`: непуст, не длиннее 39 символов (`client_id` ≤ 64), без `/`, `+`, `#`.
- `mqtt.toml` создаёт `xtask` заготовкой (`host = "192.168.1.10"`, `port = 1883`, `user = ""`, `password = ""`, `prefix = "devices"`), коммитится; `build.rs` заготовку не отвергает. `ota == "true"` и пустой `user` → `cargo::warning`, не ошибка.
- Перед отчётом: `cargo xtask lint`, `cargo xtask test host`, `cargo test --manifest-path chip-data-gen/Cargo.toml`, `template-check --only <новые случаи>` — по одной, `EXIT=0`.

## Review Focus

1. Брокер недоступен / отказал в `CONNECT` (неверный пароль) → узел не падает, лог с адресом и «проверьте mqtt.toml», паузы растут до 30 с — тесты `refused_connect_reports_refused` (Task 3), `backoff_grows_to_cap`, `quick_redial_is_paced` (Task 4), `node_redials_after_refusal` (Task 5).
2. Обрыв посреди Online (сокет вернул ошибку/EOF) → `Ended::Lost`, повтор без паники — тесты `transport_error_ends_session` (Task 3), `node_redials_after_loss` (Task 5).
3. Команда `cmd/reboot` с retain (оставлена кем-то на брокере) → не перезагружаемся — тест `retained_reboot_is_ignored` (Task 3).
4. Чужая/неизвестная тема или мусор в payload → лог, сессия продолжается — тест `unknown_command_keeps_session` (Task 3).
5. `mqtt.toml` с битым IP, портом 0, длинным/недопустимым `prefix` → сборка падает с понятным текстом — проверки в `parse_mqtt_toml` и тест `bad_mqtt_toml_is_rejected` (Task 6).
