## Claude Code

Ниже — то, что верно только для Claude Code, а не для агентов, следующих
одному лишь `AGENTS.md`.

- **`crates-cross/**` не покрыт графовыми инструментами `codebase-memory-mcp`.**
  Файлы там содержат Liquid (`{{ }}`, `{% %}`) и до генерации не являются
  валидным Rust — граф строится по дереву разбора, а для таких файлов оно не
  строится. Работать с этой частью приходится обычным чтением и поиском по
  тексту (Read/Grep), а не `search_graph`/`trace_path`/`get_code_snippet`.
